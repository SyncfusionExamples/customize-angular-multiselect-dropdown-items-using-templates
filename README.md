# Customize Angular MultiSelect Dropdown Items Using Templates

## Repository Description
A quick start Angular project demonstrating how to customize Syncfusion Angular MultiSelect Dropdown using built-in template options for UI customization.

## Overview
This repository provides a guide for customizing the Angular MultiSelect Dropdown component from Syncfusion using templates. It includes examples for tailoring list items, selected values, headers, footers, group titles, and no records content.

## Features
- Customize list items with templates
- Customize selected value display
- Customize header and footer sections
- Customize group titles and no records messages
- Built-in template option integration
- Quick start project setup
- Code examples included

## Customization Options
Templates for:

- List Items: Control appearance of individual dropdown items
- Selected Value: Customize how selections display
- Header & Footer: Add custom content to dropdown sections
- Group Titles: Customize grouped item headers
- No Records: Customize empty state messages

## Prerequisites
- Angular 4 or higher
- TypeScript 2.6 or higher
- Node.js and npm

## Installation

Clone and set up the project:

```
git clone angular-example
cd angular-example
npm install
```

## Running the Application

Start the development server:

```
ng serve
```

Navigate to `http://localhost:4200/`. The application automatically reloads on source file changes.
